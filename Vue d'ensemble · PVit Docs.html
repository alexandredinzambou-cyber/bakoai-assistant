Documentation développeur de PVit

Intégrez les paiements Mobile Money, les paiements par carte Visa/Mastercard et les autres services financiers disponibles sur PVit à partir d'une API unique.

Démarrage rapide

Accepter un paiement Mobile Money

Initiez une demande de paiement sur le numéro de téléphone d'un client. La clé passée dans l'en-tête X-Secret est obtenue au préalable via l'API Renew Secret.

1curl --request POST \
2 --url 'https://api.mypvit.pro/v2/{{code_url_payment}}/rest' \
3 --header 'X-Secret: {{secret_key}}' \
4 --header 'Content-Type: application/json' \
5 --data '{
6 "amount": 150,
7 "reference": "ORDER-2026-0001",
8 "service": "RESTFUL",
9 "transaction_type": "PAYMENT",
10 "operator_code": "AIRTEL_MONEY",
11 "customer_account_number": "074000000",
12 "merchant_operation_account_code": "{{operation_account_code}}",
13 "callback_url_code": "{{callback_url_code}}",
14 "owner_charge": "CUSTOMER"
15 }'

Accepter un paiement par carte

Les paiements Visa/Mastercard passent par l'API de lien de paiement. PVit renvoie une URL qui ouvre le formulaire bancaire sécurisé.

1curl --request POST \
2 --url 'https://api.mypvit.pro/{{code_url_link}}/link' \
3 --header 'X-Secret: {{secret_key}}' \
4 --header 'Content-Type: application/json' \
5 --data '{
6 "amount": 5000,
7 "reference": "ORDER-2026-0002",
8 "service": "VISA_MASTERCARD",
9 "transaction_type": "PAYMENT",
10 "customer_account_number": "074000000",
11 "merchant_operation_account_code": "{{operation_account_code}}",
12 "callback_url_code": "{{callback_url_code}}",
13 "success_redirection_url_code": "SUCCESS123",
14 "failed_redirection_url_code": "FAILURE123",
15 "owner_charge": "CUSTOMER"
16 }'

Redirigez le client vers l'url renvoyée. À la fin du parcours, il est ramené vers l'une de vos URLs de redirection (succès ou échec), et le statut définitif vous parvient par callback.

Vérifier une transaction

Consultez l'état d'une transaction à partir de son identifiant PVit et du compte d'opération utilisé.

1curl --request GET \
2 --url 'https://api.mypvit.pro/{{code_url_status}}/status?transactionId=PAY23102400001&accountOperationCode={{operation_account_code}}&transactionOperation=PAYMENT' \
3 --header 'X-Secret: {{secret_key}}'

Les statuts renvoyés sont PENDING, SUCCESS, FAILED ou AMBIGUOUS.

Avant de commencer

Pour effectuer vos premiers tests, vous aurez besoin de :

  1. 1créer un compte marchand PVit et compléter votre profil ;
  2. 2récupérer le code URL de chaque API et définir le mot de passe de votre API Secret ;
  3. 3disposer d'un compte d'opération de test, dont le code commence par ACC_ ;
  4. 4configurer une URL de callback publique et récupérer son code — les adresses localhost et 127.0.0.1 sont refusées ;
  5. 5autoriser l'adresse IP du serveur qui appellera l'API ;
  6. 6générer votre clé secrète, valable 3 600 secondes, et prévoir son renouvellement automatique.

Comprendre une intégration PVit

Une intégration de paiement PVit repose généralement sur trois échanges.

1. Initier la transaction

Votre backend transmet à PVit le montant, le client, votre référence marchande, l'opérateur et le compte d'opération à utiliser.

2. Recevoir la réponse initiale

PVit retourne une réponse indiquant que la demande a été reçue et prise en charge, avec le statut PENDING. Cette réponse ne signifie pas que le paiement est terminé.

3. Obtenir le résultat final

Le statut définitif est obtenu :

  • par notification sur votre URL de callback, avec les frais et le montant crédité ;
  • ou par consultation de l'API de statut, si aucune notification ne vous parvient.
